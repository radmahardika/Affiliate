# Prompter Affiliate

Web app teleprompter untuk merekam video affiliate di iPhone. Teks naskah tampil di atas kamera, tapi tidak ikut terekam.

## Fitur
- Simpan banyak naskah, dengan template affiliate (Hook → Masalah → Produk → Keunggulan → Harga → CTA)
- `[penanda aksi]` tampil kuning kecil, `*kata*` untuk penekanan
- Perkiraan durasi dari jumlah kata
- Kamera + rekam video 9:16 (720p/1080p) langsung di aplikasi
- Ganti kamera depan/belakang, juga saat sedang merekam
- Teks bergulir otomatis; ketuk untuk jeda, geser untuk memindah posisi, atur kecepatan
- Hitung mundur 3-2-1, ukuran huruf dan tinggi area teks bisa diatur
- Simpan hasil ke galeri Foto lewat tombol Bagikan
- Bisa dipasang di layar utama dan dipakai offline

## Pemakaian di iPhone
1. Buka alamat aplikasi di **Safari** (harus `https://`).
2. Ketuk Bagikan → **Tambah ke Layar Utama**.
3. Izinkan kamera dan mikrofon saat diminta.

Butuh iOS 14.3 atau lebih baru.
